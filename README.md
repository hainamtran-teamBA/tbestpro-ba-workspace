# Thư mục máy công ty – Tbestpro (nhánh `may-cong-ty`)

Thư mục làm việc của Trần Hải Nam trên máy công ty (Windows). Máy nhà dùng nhánh `main` với cấu trúc riêng; nhánh này chỉ để máy nhà xem việc mới ở công ty.

| Thư mục / file | Nội dung |
|---|---|
| `CLAUDE.md` | Cách làm việc với Claude (chung hai máy, lấy từ `main` ngày 17/11) |
| `AGENTS.md` | Bản ngắn cho Codex, Antigravity (để sẵn) |
| `.claude/` | Bản gốc cấu hình AI: `rules/` (tự nạp), `skills/`, `agents/`, `commands/`, `plans/` – xem `.claude/README.md` |
| `HUONG-DAN-SKILL.md` | Hướng dẫn dùng skill (plugin mattpocock-skills) |
| `lead-automation/` | Trang LeadFlow B2B tìm khách sỉ (dự án SMS) |
| `thu-so-do/` | Bản thử sơ đồ PlantUML nhập kho (Kho 7) |
| `WMS/kho-rfid/` | Repo của dev (anh Hiếu), không đẩy lên đây |
| `tai-lieu-goc/` | File gốc, bản cũ (không đẩy lên đây) |

Dùng hằng ngày: rời máy nói **"chốt buổi"** (ghi Notion, liệt kê file, chờ OK rồi đẩy `may-cong-ty`).
