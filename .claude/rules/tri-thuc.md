# Ghi tri thức (`reference/`)

- `reference/` là kho tri thức công ty: tổ chức, hệ thống, kho, luồng đơn, kiến trúc. Tên file cho biết nội dung.
- Chỉ ghi vào `reference/` khi người dùng **đã chốt** (kèm ngày, nguồn). Đang bàn, chưa chốt thì không ghi.
- Ghi vào đúng file của mảng đó; không tạo file mới cho mỗi lần tra cứu. Không gộp các file đã tách.
- Memory (`_memory-claude/`) chỉ ghi trạng thái dự án và cách làm việc, không ghi kiến thức công ty.
