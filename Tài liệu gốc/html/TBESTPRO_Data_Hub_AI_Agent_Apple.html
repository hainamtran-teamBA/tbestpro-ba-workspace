03 / KẾT NỐI API META

Muốn lấy dữ liệu,
cần chuẩn bị gì?

Meta App+Tài sản+Quyền
1
Công ty / Admin

Chuẩn bị BM & quyền quản trị

Xác định BM, người quản trị và danh sách tài khoản Ads, Page cần kết nối.

2
IT + Admin BM

Tạo Meta App của công ty

Tạo hoặc gắn App vào BM công ty; cấu hình sản phẩm / use case phù hợp.

3
Admin BM / Agency

Gán đúng tài sản

Gán tài khoản Ads, Page cho System User theo quyền cần dùng. Tài sản agency cần được chia sẻ và kiểm tra quyền thực tế.

4
Admin BM + IT

Tạo token & cấp quyền cần thiết

Ưu tiên ads_read cho báo cáo. IT chọn quyền bổ sung theo chức năng; giữ token ở máy chủ.

5
IT + Marketing

Thử kết nối rồi mới mở rộng

Kéo thử dữ liệu một tài khoản, đối chiếu chi phí và kiểm tra Page / media truy cập được.

Báo cáo nội bộ

Thử quyền hiện có trên tài sản đủ điều kiện. Development Mode không mặc định miễn mọi xét duyệt.

Khi mở AI / Messenger / Lead

Demo đúng chức năng, xin quyền và App Review khi cần. Live Mode không tự cấp quyền API.
